## Project Description
CryptoInsight is an advanced cryptocurrency portfolio tracker inspired by CoinStats, enhanced with unique AI-powered features using Gemini AI. Our application empowers users to:

- Monitor their crypto investments with precision
- Access real-time market data
- Receive AI-driven insights and recommendations
- Make informed decisions based on advanced analytics

## Learning Objectives
- Master full-stack development with the MERN stack
- Implement AI integration in a web application
- Develop secure authentication and data protection measures
- Create responsive and intuitive user interfaces
- Integrate and manage multiple third-party APIs

## Technologies Used
- Frontend: React.js, TypeScript, Tailwind CSS, Vite
- Backend: Node.js, Express.js
- Database: MongoDB
- State Management: Redux with Redux Toolkit
- Authentication: JWT with refresh tokens
- Caching: Redis
- AI Integration: Gemini AI API

## Third-Party Services
- CoinGecko API for cryptocurrency data
- Crypto Compare API for news aggregation
- Gemini AI API for AI-powered features

## Key Features
1. Comprehensive portfolio tracking
2. AI-powered investment suggestions
3. Natural language query interface
4. Automated news summarization and sentiment analysis
5. Risk assessment and educational content generation
6. Social trading and gamification elements
7. Multi-signature wallet support
8. Virtual portfolio simulator

## Challenges Identified
